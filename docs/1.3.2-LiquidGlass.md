# 可选 Liquid Glass 界面风格

## 设计与范围

在「主题与风格」顶部加入经典 Material / Liquid Glass 两张可点击预览卡。沿用底部应用按钮和已有配色草稿机制，切换后立即应用并保存，重启保持；旧设置默认经典风格。保留莫奈、自定义色、深浅色与中英日语言，风格与配色独立。

Liquid Glass 使用随主题变化的静态柔光背景、半透明表面、细高光边缘和悬浮导航；覆盖主导航、作品卡片、设置分组、评论入口及编辑器。正文保持足够不透明度。列表卡片只绘制渐变和边缘，不逐卡进行背景模糊；模糊仅用于小面积固定导航，开启减少动态效果或系统高对比度时停用。无持续运行的背景动画，不添加图形插件或全屏滤镜。

## 架构与验证

配置放入既有 ComposeThemePreferences，旧 schema 增加可选字段，不丢失旧配色。ThemeExtension 提供统一风格查询，公共玻璃组件放在 widgets，根页面背景由统一路由过渡负责；保持导航、滚动及业务数据状态。局部预览不提前写入设置，保存失败保留已应用风格。

验证配置迁移与恢复、未知风格回退、保存失败、两种风格与深浅色、窄屏大字体、即时切换不重读日历、减少动态效果/高对比度下关闭模糊，以及列表没有逐项 BackdropFilter。发布 1.3.2+2037，沿用签名、OAuth 和固定网页登录 UA，按现有门禁构建 ARM64 APK 和 Windows 包，并推送 GitHub。

Windows 内存设置预览已检查浅色/深色材质、侧栏导航、设置分组、风格预览卡和即时切回经典模式；预览不恢复真实会话，不写入用户持久化设置。根据界面检查扩大固定应用按钮的点击区域。手机与桌面切换风格保留滚动位置、日历只请求一次的回归通过。
