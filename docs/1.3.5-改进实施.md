# 1.3.5 改进实施

日期：2026-10-31。基于 1.3.4；版本 1.3.5+2040。

## 本轮范围

- 配额统计优先读索引长度；无长度时在禁止迁移的维护窗口检查文件，避免统计搬运整份旧缓存。
- 详情基础信息、个人基础信息和通用分区加载器持有独立读取范围；重试、会话变化或销毁时取消旧读取，沿用 API 共享请求消费者保护。
- 重复页允许继续翻页，连续三页无新条目停止；保留游标不前进保护。
- 缓存统计增加受保护字节，磁盘预计释放量扣除此部分；内存单列。清理后展示扫描得到的磁盘占用减少量，此值受并发缓存写入影响，不等同于文件系统精确删除字节。
- 作品详情标签、收藏表单、空状态和统计标题抽取中英日文；保持网站认证 User-Agent 稳定。
- GitHub Windows CI 运行已有 Release AOT 图片与六类缓存回归，并保存日志；CI 测试并行度为 2。

## 验证

新增重复页中间页、重复页预算、分区重试与移除取消、翻译键一致性，以及配额扫描不迁移旧文件的回归。测试仅使用隔离目录和伪数据，不清理真实缓存，不修改账号资料。

## 后续条件

通知历史分页需先确认 p1/notify 是否提供历史分页及游标语义；当前仅有最近 40 条接口契约，不发送猜测参数冒充历史分页。独立发行清单验签仍需用户独立保管的发行密钥及受保护签名流程；不复用或更换既有 OAuth 与 APK 签名。更大范围的页面布局和玻璃效果调整需先采集真机与 Windows 帧耗时，本轮不声称已测得性能提升百分比。
