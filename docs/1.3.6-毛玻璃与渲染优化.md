# 1.3.6 毛玻璃与渲染优化

参考用户图片的淡蓝紫柔光、乳白半透明表面、细亮边、圆角搜索与悬浮导航，保留主题色及 Bangumi 内容结构。

- 仅固定导航实时模糊，半径由 16 降至 10，保留裁剪边界；高对比度和减少动态效果时继续关闭模糊。
- 卡片使用乳白或深色雾面蒙层和细边，移除每张列表卡片的大范围投影；仅导航保留轻投影。
- 悬停只保留轻位移动画，移除恒定缩放和动画投影，卡片内容隔离重绘。
- 主导航复用已创建页面；账号、仓库或父级设置更新时重建配置，保留原有惰性初始化。
- 背景为静态绘制并隔离重绘，标记复杂绘制供引擎缓存；没有逐帧噪点或额外图片资源。

验证包括深浅色真实组件渲染、按钮交互、现有无障碍与导航保留回归及正式编译测试。未进行用户设备的前后帧耗时对比，不能将结构优化表述为已测得提速百分比。
